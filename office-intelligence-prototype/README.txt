OFFICE INTELLIGENCE / NIGHTINGALE AI — INTERACTIVE HTML PROTOTYPE

How to run:
1. Unzip the package.
2. Open index.html in a modern browser.
3. Use the left navigation to move between pages.

Included pages:
- Executive Dashboard
- Scheduler
- Patient Superchart
- Billing & Financial Dashboard
- Administration Dashboard
- Patient Admission & Registration workflow

Prototype features:
- Responsive multi-page interface
- Sample healthcare operations data
- Clickable tabs, filters, modals, task actions, schedule details, and intake stepper
- Simulated Nightingale AI command assistant
- Human-review guardrails and exception workflow concepts
- No backend, database, PHI, external services, or real clinical decision support

Important:
This is a design and workflow prototype only. It is not production-ready, HIPAA compliant by itself, or intended for real patient care, billing submission, prescribing, or clinical decisions.
